A Python program that writes the one line a smart fridge would text its owner at 3am, for make.fun's "The 3AM Fridge Text" bounty. It writes the text deterministically to /output/entry.txt and verifies it by reading it back and comparing SHA-256 digests.

## Run it

```sh
python3 main.py
```
